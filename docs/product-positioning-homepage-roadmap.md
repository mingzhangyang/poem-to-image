# InkPoem 产品定位、首页差异化卖点与 6 周路线图

## 产品定位

### 定位一句话

InkPoem 是一款面向诗歌、短句与文学内容创作者的 AI 视觉出版工具，让文字准确、排版有美感、风格有文学气质。

### 面向用户

1. 中文诗歌创作者、写作者、译者
2. 小红书 / 公众号 / Instagram 上做诗句内容的账号主
3. 独立出版、小型出版社、文学社团
4. 想做“带文字的美图”但不想被 AI 乱写字的人

### 核心价值主张

不是“帮你生成一张图”，而是“帮你把一首诗出版成一张作品”。

### 和市场拉开距离的表达

- 不是通用海报编辑器，而是诗歌原生排版工具
- 不是把文字贴到图上，而是先保证文字和版式，再生成视觉
- 不是泛模板，而是懂中文、竖排、印章、题签、留白、诗意氛围

### 可直接用的品牌文案

- 把一首诗，做成一张作品。
- AI 会画图，但不懂诗的排版。InkPoem 懂。
- 为诗歌、短句和文学内容而生的视觉出版工具。
- 精美背景之外，更重要的是文字准确、版式有气质。
- 从输入诗句到可发布成品，只需要几分钟。

### 英文版简述

InkPoem is an AI-powered visual publishing tool for poetry and literary text. It combines precise typography, poem-first layout, and atmosphere-aware visuals so creators can turn a poem into a finished piece, not just an image.

## 首页差异化卖点结构

首页不要按“模板 / AI / 导出”这种通用编辑器结构写，应该按“痛点 -> 解决方式 -> 专业感 -> 使用场景”来讲。

### 1. Hero 首屏

副标题：

AI 负责氛围，InkPoem 负责文字。为诗歌、短句与文学内容打造的视觉出版工具，解决 AI 图片里文字错误、排版失控、风格不统一的问题。

主 CTA：

次 CTA：

查看示例作品

辅助短句：

支持中文、繁体、英文、日文、韩文排版

### 2. 痛点对比区

标题：

为什么通用 AI 生图工具不适合做诗歌作品？

三栏对比：

- AI 图很美，但文字常常拼错
- 加了文字，但版式不像“作品”，像“海报”
- 做一张容易，做一组统一风格很难

右侧结论：

InkPoem 的思路是先把诗排好，再让视觉为文字服务。

### 3. 核心能力区

标题：

不是给图片加字，而是为诗歌设计的创作流程

四个卖点卡片：

- 诗歌原生排版
  标题、作者、分行、留白、对齐，不再用普通文本框硬拼
- 文学气质模板
  竖排、印章、题签、杂志感、极简风，适合诗歌与短句
- AI 氛围背景
  根据诗意生成留白充足的背景，不抢文字、不乱出字
- 多平台发布
  一键导出适合小红书、Instagram、朋友圈、打印卡片的尺寸

## 未来 6 周功能优先级路线图

原则：先做“诗歌原生工作流”，再做“发布效率”，最后才做“社区感”。不要过早做广场、评论、复杂社交。

### 第 1 周：明确产品锚点，重做首屏与新手路径

目标：让用户一进来就明白这不是通用设计工具

做什么：

- 首页文案重写，统一成“诗歌视觉出版工具”
- onboarding 改成 3 步：选风格 -> 粘贴诗句 -> 导出发布
- 增加 3 组对比示例：AI 原生出字错误 vs InkPoem 成品
- 首屏 CTA 聚焦“开始做作品”，减少分散信息

成功标准：

- 新用户首屏到开始编辑的点击率提升
- 首次导出率提升

### 第 2 周：补齐“诗歌原生排版”

目标：做出真正的产品壁垒

做什么：

- 增加诗歌结构字段：标题、作者、正文、出处/注释
- 提供“诗歌模式”而不是单 textarea
- 增加分节、空行、落款样式
- 增加“标题版 / 正文版 / 作者版”不同层级字体控制
- 为中文和日文模板加入更强的竖排与题签样式

成功标准：

- 用户平均编辑时长上升
- 模板使用率和保存模板率上升

### 第 3 周：做“诗意理解”而不是 prompt 输入

目标：把 AI 背景从通用能力变成你的特色能力

做什么：

- 输入诗句后自动生成 3 个视觉方向
  例如：清冷月夜 / 墨色山水 / 纸本极简
- 每个方向附上简短解释
  例如：突出“月、霜、思乡”的意象
- 弱化自由 prompt 输入，把它降级为高级选项
- 增加“保留更多留白”“更适合文字阅读”的风格开关

成功标准：

- AI 背景生成转化率提升
- 用户修改 prompt 的频次下降，但满意度上升

### 第 4 周：一键多尺寸与发布场景

目标：从“做图”升级到“发图”

做什么：

- 新增“发布目标”预设：
  小红书封面、方图、Story、朋友圈长图、打印卡片
- 同一作品一键生成多尺寸导出
- 增加安全区提示，避免文字被平台裁切
- 导出页直接按场景命名，而不是只显示 px

成功标准：

- 单次创作的平均导出数提升
- 社媒场景预设使用率提升

### 第 5 周：系列化创作能力

目标：提高复用和留存

做什么：

- 系列模板：同一账号/作者的统一视觉风格
- “批量套版”基础版：多首诗套同一风格连续导出
- 保存品牌包：字体、印章、落款、背景倾向
- 增加“复制为下一张”工作流

成功标准：

- 模板保存率提升
- 回访用户的二次创作率提升

### 第 6 周：小范围商业化加强

目标：提高付费理由，而不是只卖积分

做什么：

- 免费版限制为基础模板和低分辨率导出
- Pro 卖点不只是更多 credits，而是：
  多尺寸批量导出、系列模板、品牌包、高级排版、高清导出
- 增加一个“创作者案例页”或“模板精选页”
- 埋点分析：从输入诗句到导出的完整漏斗

成功标准：

- 免费到付费转化提升
- 付费用户的模板保存和多尺寸导出使用率提升

## 功能优先级排序

### 最高优先级

- 诗歌结构化编辑
- 诗意理解驱动的背景推荐
- 多平台尺寸预设
- 系列模板

### 中优先级

- 双语对照排版
- 作者署名 / 题签 / 注释
- 节日与专题模板包

### 低优先级

- 社区 feed
- 点赞评论
- 泛图片编辑能力
- 复杂协作

## 一句话版路线

先证明“这工具懂诗”，再证明“它发得快”，最后再考虑“它能形成生态”。
