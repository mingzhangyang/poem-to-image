# InkPoem 差异化功能路线图

> 核心策略：让 InkPoem 成为"懂诗"的创作工具，而不是"能放文字的画图工具"。
> Google Drawings、Paint、Photoshop 什么都能做，但不理解内容。InkPoem 理解诗。

本文档在现有 6 周路线图（见 `product-positioning-homepage-roadmap.md`）基础上，规划后续差异化功能。现有 6 周计划为 **Phase 0**，本文档从 **Phase 1** 开始。

---

## 竞品对比与差异化定位

| 能力维度 | Paint / Drawings | Canva | Photoshop | InkPoem（目标） |
|---------|-----------------|-------|-----------|----------------|
| 文字排版精度 | 基础 | 中等 | 专业 | **诗歌专属**（结构感知、竖排、留白） |
| AI 背景生成 | 无 | 有（通用） | 有（通用） | **诗意驱动**（读诗→出图） |
| 诗歌内容理解 | 无 | 无 | 无 | **核心能力**（识别、推荐、自动排版） |
| 动态/视频导出 | 无 | 有（通用） | 有（复杂） | **诗歌动画**（逐句显现、配乐朗诵） |
| 学习门槛 | 低 | 低 | 高 | **最低**（粘贴诗句→一键出图） |
| 诗歌内容库 | 无 | 无 | 无 | **内置**（按情感/季节/形式浏览） |
| 社媒适配 | 手动 | 有 | 手动 | **场景原生**（平台尺寸+轮播拆分） |

**一句话差异**：别人做的是"图上加字"，我们做的是"读懂诗，再出版"。

## Phase 1：AI 深度理解（第 7-10 周）

> 目标：让 AI 从"工具"变成"懂诗的助手"，这是最大的护城河。

### 1.1 一键智能生成（第 7-8 周）

**用户场景**：用户粘贴一首诗，点击"一键生成"，得到完整的诗词卡片（背景+排版+配色+装饰），而不是手动调每个参数。

**实现拆解**：

- [ ] **诗意分析引擎**
  - 输入：诗歌文本
  - 输出：情感标签（清冷/豪放/婉约/忧伤/欢快等）、核心意象（月/山/水/花/雪等）、色调建议（冷色/暖色/水墨/明艳）
  - 实现方式：调用 LLM（Gemini/GPT）做结构化分析，返回 JSON
  - 缓存策略：相同诗文的分析结果缓存到 D1，避免重复调用

- [ ] **风格方案生成器**
  - 基于诗意分析结果，生成 3 个完整设计方案
  - 每个方案包括：模板选择、配色方案、背景 prompt、字体推荐、装饰元素建议
  - 方案附带简短解释（如："突出'月、霜、思乡'的清冷意象"）
  - 用户选择方案后一键应用全部设置

- [ ] **智能背景 prompt 生成**
  - 不再让用户写 prompt，而是根据诗意自动生成高质量 prompt
  - prompt 内置"留白充足""不含文字""适合文字叠加"等约束
  - 支持用户在自动 prompt 基础上微调

**技术方案**：
```
用户粘贴诗文 → API: /api/ai-analyze-poem
  → LLM 返回结构化分析 { emotions, imagery, palette, form }
  → 前端展示 3 个方案卡片
  → 用户选择 → 一键应用所有设置 + 触发背景生成
```

**API 新增**：
- `POST /api/ai-analyze-poem` — 诗意分析，返回情感/意象/配色/形式
- 成本：1 credit（纯文本 LLM 调用，成本低于图片生成）

**成功标准**：
- 使用一键生成的用户占比 > 40%
- 从粘贴诗句到首次导出的平均时间缩短 50%
- AI 背景生成满意度提升（修改 prompt 频次下降）

### 1.2 诗词识别与自动填充（第 9 周）

**用户场景**：用户粘贴"床前明月光"，app 自动识别出《静夜思》，补全标题"静夜思"、作者"李白"、全文、出处。

**产品原则**：Phase 1 采用离线优先（offline-first），用户主流程不依赖 poem library 在线 API。

**实现拆解**：

- [x] **诗词库构建（MVP）**
  - 数据源：仅收录可确认公共领域作品（含来源链接、版权状态、整理版本）
  - 存储：打包为静态 JSON 分片（按语言/体裁拆分）
  - 索引：建立关键句→诗词 ID 的倒排索引（压缩后随前端发布），支持模糊匹配
  - 规模：初期 2000-3000 首经典诗词，覆盖最常见的引用
  - 数据字段最小集：`id/title/author/text/source/license_status/license_note`

- [x] **智能识别匹配（MVP）**
  - 用户输入文本后，实时匹配已知诗词（前端本地匹配，无需 API 调用）
  - 在 Web Worker 中执行匹配，避免阻塞主线程
  - 匹配到时弹出提示："这是李白的《静夜思》，是否自动补全？"
  - 自动填充：标题、作者、完整正文、出处朝代
  - 未匹配时不干扰，保持现有手动输入流程

- [ ] **离线性能控制**
  - 首屏只加载当前语言索引，其他语言按需懒加载
  - 匹配延迟目标：输入后 150ms 内返回候选
  - 资源预算：诗词库+索引 gzip 后 < 2.5MB（超限则拆分二级包）

- [ ] **诗词浏览库**
  - 新增"诗词库"入口（侧栏 tab 或模态框）
  - 分类浏览：按情感（思乡/爱情/山水/咏史）、季节（春夏秋冬）、形式（五绝/七律/词/十四行诗/俳句）
  - 搜索：支持按标题、作者、关键词搜索
  - 点击即导入到编辑器

**成功标准**：
- 诗词库使用率 > 20%
- 自动识别命中率 > 80%（针对经典诗词）
- 手动输入作者/标题的比率下降

### 1.3 诗词形式感知排版（第 10 周）

**用户场景**：app 识别出这是一首五言绝句，自动采用竖排+居中+印章的经典排版；识别出是俳句，自动采用极简留白布局。

**实现拆解**：

- [ ] **形式识别器**
  - 检测规则：行数、每行字数、韵脚、语言
  - 支持的形式：
    - 中文：五言/七言（绝句/律诗）、词（按词牌）、现代诗、散文诗
    - 日文：俳句（5-7-5）、短歌（5-7-5-7-7）
    - 英文：sonnet（14行）、haiku、limerick、free verse
  - 返回形式标签 + 推荐排版参数

- [ ] **形式→排版映射表**
  - 五言/七言绝句 → 竖排、居中、宽松行距、配印章
  - 律诗 → 竖排、双列、题签
  - 词 → 竖排、分片显示（上阕/下阕）
  - 俳句 → 横排、极简、大量留白、小字号
  - Sonnet → 横排、衬线字体、经典比例
  - 现代自由诗 → 横排、左对齐、紧凑行距
  - 映射表可扩展，未来可由用户自定义

- [ ] **自动应用排版建议**
  - 识别到形式后，作为智能生成方案的一部分推荐
  - 不强制覆盖用户已有设置，以提示方式展示
  - "检测到这是一首七言绝句，推荐使用竖排+印章排版？[应用]"

**成功标准**：
- 形式识别准确率 > 90%（经典形式）
- 使用推荐排版的用户比率 > 50%

## Phase 2：富媒体与动态内容（第 11-14 周）

> 目标：从静态图片扩展到动态内容，打开短视频平台的全新流量入口。

### 2.1 诗词动画导出（第 11-12 周）

**用户场景**：用户创作完诗词卡片后，选择"导出为视频"，得到文字逐句显现、背景微动的 15 秒短视频，直接发抖音/Reels。

**实现拆解**：

- [ ] **文字动画引擎**
  - 逐句/逐字显现（fade in、打字机效果、毛笔书写效果）
  - 动画时序自动计算：根据诗句长度和总时长分配每句显现时间
  - 预设动画风格：
    - 淡入淡出（通用）
    - 打字机（现代感）
    - 墨迹扩散（中国风）
    - 逐字滑入（日系）

- [ ] **背景微动效**
  - Ken Burns 效果（缓慢缩放/平移）
  - 粒子飘落（雪花/花瓣/落叶，根据诗意自动选择）
  - 光影变化（日出渐变、月光闪烁）
  - 基于 Canvas/WebGL 实现，不依赖视频编辑库

- [ ] **视频合成与导出**
  - 技术选型：浏览器端使用 Canvas + MediaRecorder，默认导出 WebM / GIF
  - MP4（H.264）仅云端渲染（Pro 路径），避免浏览器编码兼容性问题
  - 导出格式：WebM（默认）、GIF（短循环）、MP4（云端 Pro）
  - 导出分辨率：720p / 1080p
  - 视频时长：5s / 10s / 15s / 30s 可选

- [ ] **配乐选择（可选）**
  - 内置 5-10 首免版权背景音乐（古风/钢琴/环境音）
  - 按诗意情感自动推荐
  - 支持静音导出
  - 音频来源：公共领域古典音乐片段 or 授权 CC0 音乐

**技术风险与应对**：
- 浏览器端视频编码性能有限 → 限制最大分辨率为 1080p，提供"云端渲染"作为 Pro 功能
- Safari / iOS 编码兼容性不足 → 降级为 GIF 或序列帧 ZIP，提示切换到云端 MP4

**成功标准**：
- 视频导出功能使用率 > 15%
- 视频导出完成率 > 80%（不因性能问题放弃）
- 社媒端的分享/播放引流效果

### 2.2 朗诵音频 + 有声卡片（第 13 周）

**用户场景**：用户点击"朗诵"，AI 用优美的声音朗读诗词，合成为有声视频卡片。或者用户自己录制朗诵。

**实现拆解**：

- [ ] **TTS 朗诵**
  - 接入 TTS API（Google Cloud TTS / OpenAI TTS / Edge TTS）
  - 中文：选择有感情的朗诵音色（不要机器人感）
  - 英文：选择适合诗歌的慢速、有韵律的音色
  - 用户可调节：语速、音色选择

- [ ] **用户自录朗诵**
  - 浏览器端录音（MediaRecorder API）
  - 简单的音频裁剪（选择起止点）
  - 录音波形可视化

- [ ] **音画合成**
  - 将朗诵音频与视频动画合成
  - 自动对齐：根据音频时长调整文字动画节奏
  - 导出为带音频的 MP4

**成本控制**：
- TTS 按字符计费 → 一首诗通常 < 200 字，成本极低
- 定价：TTS 朗诵消耗 1 credit

**成功标准**：
- 有声卡片导出占视频导出的 > 30%
- 用户分享有声卡片的比率高于静态图片

### 2.3 Instagram 轮播自动拆分（第 14 周）

**用户场景**：一首长诗自动拆分为 5 张风格统一的 Instagram carousel slides，每张 2-4 行，保持封面感。

**实现拆解**：

- [ ] **智能拆分算法**
  - 按语义/分节拆分，不在句中断开
  - 每张 slide 的文字量均衡
  - 第一张为封面（标题+作者+首句）
  - 最后一张为落款（末句+出处+印章）

- [ ] **系列一致性保持**
  - 所有 slides 共享相同背景风格（可微变化）
  - 字体、配色、装饰元素一致
  - 页码标记（可选）：1/5, 2/5 ...

- [ ] **批量导出**
  - 一键导出所有 slides 为 zip
  - 按平台命名：slide-1.jpg, slide-2.jpg ...
  - 支持预览整组 carousel

**成功标准**：
- 长诗（>8行）的轮播导出使用率 > 25%

## Phase 3：独特视觉效果（第 15-18 周）

> 目标：提供 Paint/PS 难以快速实现的诗歌专属视觉效果。

### 3.1 书法与手写渲染（第 15-16 周）

**用户场景**：用户选择"书法模式"，诗句以毛笔书法风格渲染，不只是换字体——有笔锋、有墨迹浓淡变化。

**实现拆解**：

- [ ] **AI 书法生成**
  - 方案 A：调用图像生成 API，prompt 指定书法风格+具体文字，生成书法文字图层
  - 方案 B：使用开源书法字体集（更可控、更快、零 API 成本）
  - 推荐：先做方案 B（字体集），Phase 后期探索方案 A（AI 生成）

- [ ] **书法字体扩展**
  - 接入更多书法字体：楷书、行书、草书、隶书、篆书
  - 日文书法字体：毛筆体
  - 英文 calligraphy 字体：Copperplate、Spencerian 风格
  - 字体预览和推荐（根据诗歌形式推荐字体风格）

- [ ] **墨迹效果**
  - CSS/Canvas 滤镜模拟墨迹晕染
  - 笔画粗细变化（通过 SVG 滤镜或 Canvas 后处理）
  - 浓淡渐变效果（首字浓→末字淡）

### 3.2 纸张质感模拟（第 17 周）

**用户场景**：用户选择"宣纸"质感，背景呈现真实宣纸纤维纹理，墨迹有渗透感。

**实现拆解**：

- [ ] **质感纹理库**
  - 宣纸（生宣/熟宣）
  - 羊皮纸 / 牛皮纸
  - 手工棉纸
  - 复古信纸（横线/方格）
  - 现代纹理纸
  - 格式：高分辨率无缝贴图（tileable texture）

- [ ] **纹理应用方式**
  - 作为背景层叠加（multiply / overlay 混合模式）
  - 可与纯色/渐变/AI 背景叠加使用
  - 不透明度可调
  - 老化/做旧程度滑块（色调偏黄、边缘磨损）

- [ ] **墨纸交互效果**
  - 文字边缘的墨迹渗透感（Canvas 模糊+扩散滤镜）
  - 与纸张质感的混合模式配合
  - 轻量级实现，不显著影响导出速度

### 3.3 装饰元素与诗意联动（第 18 周）

**用户场景**：诗中有"月"和"霜"，app 自动推荐月亮、霜花相关的装饰素材。

**实现拆解**：

- [ ] **意象→素材映射库**
  - 构建"意象关键词→装饰素材"映射表
  - 常见意象覆盖：月、花、雪、山、水、竹、松、鹤、云、雨、风、酒、剑、灯等
  - 每个意象对应 3-5 个 SVG/PNG 装饰素材
  - 素材风格：水墨、极简线条、浮世绘

- [ ] **AI 意象提取**
  - 复用 Phase 1 的诗意分析结果中的意象字段
  - 在装饰面板中展示"推荐装饰"区域
  - 一键添加推荐素材到画布

- [ ] **装饰素材库扩展**
  - 当前已有：边框（14种）、印章、签名
  - 新增：角花、分隔线、背景图案、水印素材
  - 分类：中国风、日式、西方古典、现代极简

## Phase 4：内容生态与社区（第 19-22 周）

> 目标：从工具到平台，建立网络效应。注意：社区功能在产品核心体验打磨完成后再启动。

### 4.0 合规基线（上线阻断项）

- [ ] **下架与申诉机制（Takedown SLA）**
  - 用户可在作品页发起举报（版权/侵权/不当内容）
  - SLA：24 小时内响应，72 小时内完成下架或驳回并给出理由
  - 被下架内容默认不可见；保留证据快照与处理日志
- [ ] **创作者声明与授权确认**
  - 发布时要求勾选"我确认拥有发布内容的合法使用权"
  - 对诗文类内容记录来源类型（自创/公共领域/已授权）
- [ ] **运营后台能力**
  - 审核队列、处理状态、处理人、处理时间
  - 支持复核与恢复，保留完整审计轨迹

### 4.1 公开画廊（第 19-20 周）

**用户场景**：用户浏览其他人的诗词卡片作品，获取灵感，一键使用同款模板。

**实现拆解**：

- [ ] **作品发布流程**
  - 导出时增加"发布到画廊"选项
  - 用户选择：公开 / 仅链接可见 / 私密
  - 自动提取元信息：诗歌文本、模板配置、标签
  - 发布前增加版权声明确认（与 4.0 合规基线一致）

- [ ] **画廊浏览页**
  - 瀑布流展示
  - 筛选：按语言、风格、情感、形式
  - 排序：最新、最热、编辑推荐
  - 搜索：按诗句、作者、标签

- [ ] **模板复用**
  - 浏览作品时可"使用同款风格"
  - 复制模板配置（不复制诗歌文本——尊重原创）
  - 显示"N 人使用了此风格"

- [ ] **举报入口**
  - 每个公开作品提供"举报"入口（侵权/不当内容）
  - 举报后进入审核流程，支持补充说明与证据链接

- [ ] **每日推荐**
  - "今日诗词"：每天推荐一首诗 + 一个风格方案
  - 自动化：从诗词库按日期/节气/节日选择
  - 用户可一键基于推荐开始创作

**数据模型新增**：
```sql
CREATE TABLE gallery_posts (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  image_url TEXT NOT NULL,       -- 存储到 R2
  poem_text TEXT,
  template_config TEXT,          -- JSON，可被他人复用
  tags TEXT,                     -- JSON array
  visibility TEXT DEFAULT 'public',
  likes_count INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE gallery_likes (
  user_id TEXT NOT NULL,
  post_id TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  PRIMARY KEY (user_id, post_id)
);

CREATE TABLE content_reports (
  id TEXT PRIMARY KEY,
  post_id TEXT NOT NULL,
  reporter_user_id TEXT,
  report_type TEXT NOT NULL,      -- copyright / abuse / other
  report_reason TEXT,
  status TEXT DEFAULT 'open',     -- open / reviewing / resolved / rejected
  created_at TEXT DEFAULT (datetime('now')),
  resolved_at TEXT
);

CREATE TABLE takedown_actions (
  id TEXT PRIMARY KEY,
  post_id TEXT NOT NULL,
  report_id TEXT,
  action TEXT NOT NULL,           -- hide / restore / reject
  operator_user_id TEXT NOT NULL,
  action_reason TEXT,
  created_at TEXT DEFAULT (datetime('now'))
);
```

**成功标准**：
- 画廊浏览 PV > 创作页 PV 的 30%
- "使用同款风格"的转化率 > 10%
- 画廊发布率（导出用户中选择发布的比率）> 15%

### 4.2 诗词挑战 / 主题活动（第 21 周）

**用户场景**：本周主题是"春天"，用户围绕春天创作诗词卡片，画廊首页展示本周主题作品集。

**实现拆解**：

- [ ] **主题运营系统**
  - 管理后台创建主题活动（标题、描述、时间范围、推荐诗词）
  - 画廊首页展示当前活动 banner
  - 用户发布时可标记参与活动
  - 作品与活动建立关联关系（用于参与率统计与活动页聚合）

- [ ] **主题内容包**
  - 每个主题配套：推荐诗词列表、推荐模板、推荐配色
  - 节气/节日主题自动排期（清明、中秋、七夕、Valentine's Day 等）

**成功标准**：
- 活动期间日活提升 > 20%
- 活动参与率（活动期间发布中标记活动的比率）> 30%

### 4.3 诗集导出（第 22 周）

**用户场景**：用户选择 10 首诗，统一风格，导出为一本完整的 PDF 诗集，带封面和目录。

**实现拆解**：

- [ ] **诗集编辑器**
  - 从已保存的作品中选择多首诗组成诗集
  - 调整顺序（拖拽排序）
  - 统一风格（一键应用相同模板到所有页面）

- [ ] **封面与目录生成**
  - 自动生成封面（诗集标题+作者+风格化背景）
  - 自动生成目录页（诗名列表）
  - 封面/目录可编辑

- [ ] **PDF 导出**
  - 逐页渲染为高分辨率图片 → 合并为 PDF
  - 支持 A4 / A5 / 方形 尺寸
  - 含出血区（bleed）标记，适合印刷

**定价**：Pro 功能，免费用户限 3 首/集

**成功标准**：
- 诗集功能使用率 > 5%（小众但高价值）
- Pro 转化贡献率

## 一句话版路线

Phase 0（现有）做"诗歌原生工作流" → Phase 1 做"AI 懂诗" → Phase 2 做"动态内容" → Phase 3 做"视觉升级" → Phase 4 做"社区生态" → Phase 5 做"实体融合"。

**核心判断标准**：每个 Phase 的功能是否让"InkPoem 比通用工具更懂诗"这件事更加成立。如果不是，就不急着做。
